# How to design an app shell

1. Open the built-in **app-shell** from Client Components (Kind filter: BuiltIn or Shell). Click the card title to edit it; the first save writes your copy. Duplicate it if you need a separately named shell.
2. Customize header, sidebar, logo, and content outlet regions from the shell-chrome palette.
3. Assign **navigationRef** on nav slots to a navigation manifest.
4. Save and preview at desktop and mobile viewports, then pick that shell on the Portals page.
