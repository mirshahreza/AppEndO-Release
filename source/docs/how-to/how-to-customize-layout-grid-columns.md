# How to customize layout grid columns

**Column Sizes** (`layoutGridColumnWidths`) controls each column in a layout grid row.

1. Insert a **Layout grid** from the toolbox.
2. Select the grid container and open **Tailwind Utilities → Column Sizes**.
3. Enter widths such as `20%`, `70%`, or `1fr` per column.
4. Preview and export — codegen emits matching `gridTemplateColumns` styles.
