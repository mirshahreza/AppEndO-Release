# UI design system (tokens)

> **Shard:** `ui-design-system` · **Wins over** other UI shards for color, typography, spacing, radius, elevation, iconography.

Fluent 2 token discipline on Tailwind v4 + HeroUI v3 — **not** a Fluent React migration. Living controls: Base Components `/studio/base-components`.

Audit backlog (not rules): [`docs/architecture/ui-fluent2-audit.md`](../architecture/ui-fluent2-audit.md).

## Intent

Every color, type, space, radius, shadow, and icon decision uses the tables below. Do not invent a parallel scale in a feature file.

## 1. Color — three tiers, never mixed

Pick exactly one tier. If you cannot, stop.

### Tier 1 — Accent / theme (`--app-accent-*`, `--color-primary-*`)

Operator-customizable via `AccentColorPicker`. Generated by `harmonizeAccentHex` / `buildAccentCssVars` (`src/shared/theme/accentColorUtils.ts`).

**10% rule — reserved for:**
1. Primary/CTA buttons (`ButtonIntent: 'primary' | 'create'`) — fill uses the AA-safe 600 stop.
2. Active sidebar item indicator + active text/icon (not the sidebar or header fill).
3. Focused input borders and progress bars.
4. Brand mark (logo gradient).
5. Loading splash radials (`--gradient-shell-atmosphere`) — paper linear wash, whisper of accent.
6. Nested-editor inspector wash (`--app-inspector-rail-bg`) — **3.5%** `--app-accent-rgb` into `--app-accent-soft` (sidebar-paper whisper, not a slab) ([`ui-inspector-rail.md`](./ui-inspector-rail.md)).

**Never** for sidebar/header/page body fills, content-area icon wells, category badges, per-object coloring, workflow node decoration, charts, status badges, or dashboard widget backgrounds.

Chrome surfaces are **neutral slate**, generated independently of accent:
- Cards `#FFFFFF` · page body / shell `#F8FAFC` · muted wells `#F1F5F9` · dark `#111827`
- Secondary icons sit on `#F1F5F9`; the glyph may use accent ink.

Ink (`--app-accent-700`) and button fill (`--app-accent-600`) are contrast-corrected to WCAG AA against white across Light / Soft / Core / Rich / Deep. Body text uses `#334155` or `#0F172A` — never a low-contrast tinted shade.

**Appearance workspace** (`pageKey: appearance`, nav label **Appearance**) is the single hub for accent color, atmosphere tokens, shell behavior (sidebar default/collapse policy, page width), and admin **portal defaults** (platform blob `appearancePortalDefaults` per mount). **Admin** sets portal defaults in Appearance; those apply to every user until overridden. **Users** override personal prefs in the same workspace (`shell_experience` USER attribute, loaded after login). Reset personal shell prefs returns to portal defaults; Reset swatch restores the public Theme Designer catalog for the active accent.

Saved Theme Designer tokens belong to the **logged-in user** (`theme_presets`, same scope as `accent_theme`). The public catalog in `workspace/appearance/` is the default each user starts from; Reset restores that catalog for the active swatch. `reconcileNeutralChromeTokens` restamps only non-catalog derived chrome / status glows. Generator defaults keep sidebar/header/page slate until the user edits those controls. Chrome frost (`--app-sidebar-fill-opacity`, `--app-header-fill-opacity`) and line textures (`--app-menu-texture-opacity`, `--app-header-texture-opacity`) default to `0%`. Dashboard page fill uses `bg-surface-shell` so it tracks `--app-shell-bg`. The login screen stays the fixed default accent and does not load a user's Theme Designer tokens.

### Tier 2 — Object / semantic palette

Fixed Tailwind hues, **independent of accent**. Source: `src/shared/ui/paletteHues.ts`.

Use when a page has named objects/categories/groups: nav rail icons, modeler field-groups, badges, entity-type icons.

Core 7: `slate` · `indigo` · `violet` · `cyan` · `emerald` · `amber` · `rose`  
Extended: `blue` · `purple` · `teal`

Recipe (small-area only): tinted icon `text-{hue}-600`, optional badge `bg-{hue}-50` / `border-{hue}-200`, optional title `text-{hue}-800`. **Never** a full panel/page wash.

**Always visible at rest** for category identification. Hover/active may add emphasis; they must not be the only time color shows.

### Tier 3 — Neutral & status

- **Neutral:** slate ramp only. Page shell, modal body, grid host, card surfaces.
- **Status (fixed hex, never remapped by accent — including Cranberry / Gray):**
  - Success / Ready / Connected → **emerald** `#10B981`
  - Warning / caution → **amber** `#F59E0B`
  - Danger / error → **red** `#EF4444`
  - Info / in-progress → **cyan**

If accent collides with a status hue, status still wins in status contexts.

| You're coloring… | Tier |
|---|---|
| Primary button, active nav indicator/text, focus border, logo | 1 |
| Nav/section icon, group header, entity badge, category chip | 2 |
| Page/modal/card/sidebar/header background, body text, dividers | 3 Neutral |
| Error/warning/success/info badge, toast, validation border | 3 Status |

## 2. Typography — one ramp

Productive studio chrome (Fluent 2 Body1 density). **html/body stay at 16px** — never shrink rem globally. Consume `src/shared/ui/typographyRoles.ts` (`TYPE_*`). Do not invent a parallel scale in a feature file.

| Role | Token | Class | Used for |
|------|-------|-------|----------|
| Title | `TYPE_PAGE_TITLE_CLASS` | `text-sm font-bold tracking-tight` | Shell page title. Dialog primary header is the same size (`DIALOG_PRIMARY_HEADER_TITLE_CLASS`). |
| Subtitle | `TYPE_SECTION_TITLE_CLASS` | `text-xs font-semibold` | Panel/dialog subsection, named group header, catalog card **human** titles |
| Identifier | `TYPE_IDENTIFIER_CLASS` | `font-mono text-xs font-normal` | Table names, function names, slugs, PK tokens |
| Eyebrow | `TYPE_EYEBROW_CLASS` | `text-xs font-semibold uppercase tracking-wider` | FormSection / grouping headers — **never** a field label. Pass sentence-case titles; `FormSection` CSS-uppercases and draws the ink bar. Do not restyle. How to author groups: [`ui-core.md`](./ui-core.md) §Form sections |
| Body | `TYPE_BODY_CLASS` | `text-sm font-normal` | Default body, descriptions |
| Field label | `TYPE_FIELD_LABEL_CLASS` | `text-sm font-normal` | Every form field label (including **new** Settings fields) |
| Field value | `TYPE_FIELD_VALUE_CLASS` / `HERO_UI_FIELD_VALUE_CLASS` | `font-semibold text-slate-900` | Input, select, textarea, and readonly field boxes |
| Caption / meta | `TYPE_CAPTION_CLASS` | `text-[11px] font-normal` | Timestamps, helper text, catalog meta — **never** `font-semibold` |
| Micro | `TYPE_MICRO_CLASS` | `text-[10px]` | Dense counts/badges only |

Weights: `font-normal` (400) body / caption / identifier / **field labels**, `font-semibold` (600) **field values** and section titles, `font-bold` (700) page titles. **Never** `font-medium` as a fourth weight. Uppercase + `tracking-wider` is Eyebrow only.

Catalog inventory (Data Studio tables, Server Functions): `DevelopmentCatalogCardHeader` `titleTone="identifier"` + denser grid (`xl:grid-cols-5` / `2xl:grid-cols-6`). Human-named cards keep `titleTone="label"`.

**Existing Settings screens** still use `getSettingsTypography()` (`text-[11px] font-bold uppercase` on labels). Do not ad-hoc mix; new Settings fields use **Field label**. Wholesale Settings migration is a dedicated pass, not a drive-by.

## 3. Spacing

Tailwind 4px scale (`gap-1`=4px, `gap-2`=8px, …). Two intentional exceptions — do not “fix” them:

- Label-to-control gap: exactly `2px` (`gap-[2px]`) — [`ui-core.md`](./ui-core.md)
- 1px optical nudges (checkbox `translate-y-px`; radio via `HERO_UI_RADIO_LABEL_NUDGE_CLASS`)

No new `gap-[Npx]` / `p-[Npx]` beyond those families.

## 4. Radius

`--app-radius-*` in `src/index.css` remaps every named `rounded-*`. **MUST** use named `rounded-*`. **NEVER** `rounded-[Npx]` (bypasses the remap). Existing `rounded-[6px]` in `formChoiceLayout.ts` is debt — do not copy it.

## 5. Elevation

Use named tokens in `surfaceClasses.ts` — not ad-hoc `shadow-*`:

| Token | Class | Use |
|-------|-------|-----|
| `SHADOW_FLAT` | `shadow-none` | Inline content, flush panels, grid cells |
| `SHADOW_RAISED` | `shadow-sm` | Cards, chips, buttons, row hover |
| `SHADOW_FLOATING` | `shadow-lg` | Dropdowns, popovers, floating panels, tooltips |
| `SHADOW_MODAL` | `shadow-2xl` | Modals, wizards only |

## 6. Icons

- Lucide only. No second icon set.
- Sizes: `h-3 w-3` (12px chip) · `h-3.5 w-3.5` (14px default button/nav) · `h-4 w-4` (16px section) · `h-5 w-5` (20px page/empty). Nothing else.
- Default Lucide stroke (2). Do not override per instance.
- Color: slate for structural icons; Tier 2 when the icon **is** a category; Tier 1 only for reserved roles; Tier 3 status only when the icon **is** status.
- **Icon beside a title or label:** put them in one `inline-flex items-center` row with a gap — `gap-1.5` compact (buttons, option-card titles, chips) or `gap-2` page/section headers (`ICON_LABEL_ROW_CLASS` / `PAGE_HEADER_ICON_TITLE_CLUSTER_CLASS` in `surfaceClasses.ts`). Never let a Lucide glyph sit flush against text; constrain the SVG (`h-3.5`/`h-4` + `overflow-hidden` / `PAGE_HEADER_ICON_SLOT_CLASS`) so the stroke cannot overflow into the letters. Nav rails already use `gap-3` (`WORKSPACE_SECTION_NAV_LINK_BASE_CLASS`).

| Category | Owns it |

`AppButton` + `buttonSemantics.ts` is the canonical button. Do not add a fourth button primitive.
